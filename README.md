# Our Story ❤️

GitHub-ready static website for the story.

## How to use

1. Create a new GitHub repository.
2. Upload **all files and the `assets` folder** exactly as they are.
3. Open `index.html` to test locally, or enable **GitHub Pages** in the repository settings.
4. If you want to replace a memory, keep the same filename (`photo-1.jpg` etc.) so the site code does not need changing.
5. The December ending has 3 placeholders where you can later add the extra 2–3 December photos.
